# NXTR: font ve Türkçe harfler

1. `AGENTS.md`'yi baştan sona oku.
2. `docs/rehber/font.md` rehberini baştan sona oku; ayrıntı için `docs/formats/tmp-font.md`.
3. Uygulamada Kontrol Et → Fontları Tara çalıştır ve tablodaki sayıları (eksik harfler, "Yamayla eklenir") kullanıcıya
   aktar. Sırayla: fontta zaten var mı → font yaması → harf dönüştürme.
4. Yeni font biçiminde önce biçimi çöz, elle üretilmiş örnek fontla test yaz, yazılan dosyayı yeniden okuyup harfin
   gerçekten var olduğunu doğrula.
5. Dışa aktar, `NXTR - Bilgi.txt`'teki eklenen/eklenemeyen harfleri raporla. Cihazda göz kontrolünü kullanıcıdan iste;
   denenmediyse "cihazda denenmedi" yaz.
